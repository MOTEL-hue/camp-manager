# ניהול קייטנות ומכירות

תוכנת ווינדוס בעברית לניהול רשימות, רישום לקייטנות, מכירת מוצרים (למשל ספרים), תשלומים,
הוצאות וסיכומים. עובדת בלי אינטרנט, ומתעדכנת לבד לגרסה חדשה כשיש חיבור.

## התקנה

1. נכנסים ל-[דף הגרסאות](https://github.com/MOTEL-hue/camp-manager/releases/latest) ומורידים את
   `camp-manager-setup-....exe`.
2. פותחים את הקובץ. ההתקנה בעברית ובלחיצה אחת. ווינדוס עלול להציג "Windows protected your PC", כי לתוכנה אין חתימה
   דיגיטלית בתשלום. לוחצים **"מידע נוסף"** ואז **"הפעל בכל זאת"**. זה קורה רק בהתקנה הראשונה.
3. נוצר קיצור דרך בשולחן העבודה.

**גרסה ניידת מהירה (בלי התקנה):** מורידים את `camp-manager-fast-portable-....zip`, פורסים לתיקייה (לחיצה ימנית ←
חילוץ הכול), ומפעילים את `camp-manager.exe` שבתוכה, גם מדיסק-און-קי. היא נפתחת מיד. הנתונים נשמרים בתיקייה
"נתוני ניהול קייטנות" שבתוך התיקייה, ועוברים איתה. עדכון רגיל מוריד רק את קוד התוכנה (1-2MB) ומחליף אותו
בסגירה; רק כשרכיב הדפדפן שבתוכה מתחלף (לעתים רחוקות) צריך להוריד zip חדש.

**גרסה ניידת בקובץ יחיד** (`camp-manager-portable-....exe`) עדיין קיימת, אבל היא מתפרקת בכל פתיחה ולכן נפתחת לאט
ומוריד 100MB בכל עדכון. בתוכנה מוצעת הדרך לעבור לגרסה המהירה (גיבוי ושחזור).

בכל הגרסאות, מכאן והלאה התוכנה בודקת לבד אם יש גרסה חדשה, מורידה אותה ומתקינה כשסוגרים את התוכנה.
בגרסה המותקנת העדכון מוריד רק את החלקים ששונו. הנתונים לא נפגעים בעדכון.

## איך עובדים

1. **פרויקט חדש** - למשל "קייטנת קיץ", "קייטנת אחרי סוכות" או "מכירת ספרים". לכל פרויקט רשימת אנשים
   משלו.
2. **אנשים** (לשונית בכל פרויקט) - מקלידים ישירות בטבלה ("הוסף אדם" או "הקלדת רשימה"), מעתיקים רשימה
   מפרויקט אחר (כולם, או רק מי שהשתתף / שילם / חייב), או, רק אם נוח, מייבאים מאקסל או PDF (או גוררים
   את הקובץ לחלון). אפשר להוסיף עמודות משלכם. ילדים עם אותו טלפון הורה מזוהים כמשפחה אחת.
   בייבוא, עמודת V יכולה להיכנס ישר ל"נרשם/ה", ל"שולם הכול" (מי ששילם נחשב גם כנרשם), ל"סכום ששולם"
   או לעמודת סימון בפרויקט. עמודות V שמופיעות בלשונית האנשים מוצגות גם בלשונית הרישום, ובחלון
   "עמודות" אפשר להפוך עמודה קיימת לרישום או לתשלום.
3. **הגדרות הפרויקט**:
   - קייטנה: מחיר שווה לכולם או לפי כיתה, ומסמנים מי נרשמה.
   - מכירה: רשימת מוצרים ומחירים, ומקלידים כמה כל אחת קנתה.
   - אפשר להוסיף עמודות סימון (אישור הורים, הביאה טופס...) והנחה אישית.
4. **תשלומים** - בכפתור 💰 ליד כל שם: סכום (גם חלקי), אמצעי תשלום, תאריך. תשלום למשפחה שלמה
   מתחלק לבד בין הילדים. אחרי כל תשלום - קבלה להדפסה או לשמירה כ-PDF.
5. **הוצאות** - זמרת, גרפיכל, נסיעות... ומולן מאזן: כמה יש עכשיו, כמה יהיה כשכולם ישלמו, וכמה
   מזומן אמור להיות בקופה.
6. **סיכום** - לפי כיתה, לפי אמצעי תשלום, לפי מוצר, ורשימת חייבים (הדפסה / העתקת טלפונים).
7. **קישור בין פרויקטים** - יוצרים פרויקט מסוג "רשימה בלבד" (למשל "רישום דרך העירייה" או "דרך המנהל")
   ומכניסים אליו את הרשימה. בהגדרות הקייטנה מוסיפים קישור אליו: מי שמופיע / נרשם / שילם שם - פטור
   כאן או מקבל הנחה קבועה, עם כיתוב שבוחרים (למשל "עירייה"). בסיכום רואים כמה ילדים וכמה כסף מכוסים.
8. **הזמנה וחלוקה** - כמה להזמין מכל מוצר, ורשימת "קיבלה" לסימון בזמן החלוקה.
   **ספקים:** בלשונית "הוצאות" מגדירים ספקים (שם, איש קשר, טלפון, מייל, כתובת, הערות) ומשייכים לכל אחד את המוצרים
   שלו (למשל חומש אצל חיים, גיאוגרפיה ונפלאות הבורא אצל ספק אחר). אז רשימת ההזמנה מתפצלת לפי ספק, עם סה"כ לכל
   ספק (אפשר להזין "מחיר מהספק" אם הוא שונה ממחיר המכירה), הדפסת הזמנה לכל ספק, ו"דוח ספקים" סופי עם כל הפרטים,
   מה להזמין, כמה שולם לו (הוצאה שסימנו על שמו) וכמה נשאר. הדוח נכלל גם בייצוא לאקסל.
9. **תזכורות וקבלות במייל** - במסך "הגדרות וגיבוי" מגדירים פעם אחת את ה-Gmail (עם "סיסמת אפליקציה"
   של גוגל) ואת קו ימות המשיח של הקייטנה. אחר כך בלשונית "סיכום" ← "📣 שליחת תזכורות": מייל, הודעה
   קולית עם הסכום, או צינוק - הודעה אחת לכל משפחה. בחלון הקבלה יש "📧 שליחה במייל" (הקבלה מצורפת כ-PDF).
   הסיסמאות נשמרות מוצפנות במחשב, בנפרד מקובצי הגיבוי.
10. **סנכרון ושיתוף** - דרך "מרכז הקייטנות" באתר (https://voice-chat-suite-rir5.onrender.com/camps/), עם
   חשבון נפרד משלו (גם מתוך התוכנה: הגדרות וגיבוי ← "חשבון במרכז הקייטנות"). בהגדרות פרויקט מסמנים
   "לסנכרן לאתר", ואפשר לשתף אותו עם מייל של חשבון אחר. עובדים גם בלי אינטרנט - כשמתחברים הכול מתאחד.
   במרכז הקייטנות יש גם הגדרה של שלוחת "בירור יתרה" לקו ימות המשיח: ההורה מתקשר ושומע כמה נשאר לשלם.
11. **היסטוריה** - פרויקטים ישנים עוברים לארכיון. אפשר לשכפל פרויקט לשנה הבאה.

כל שינוי נשמר מיד. **Ctrl+Z** מבטל את הפעולה האחרונה. בכל יום נשמר גיבוי אוטומטי (30 ימים
אחורה), ובמסך "הגדרות וגיבוי" אפשר לשמור קובץ גיבוי ולשחזר ממנו.

## פיתוח

```bash
npm install
npm start        # מריץ את התוכנה
npm test         # בדיקות החישובים והייבוא
```

פרסום גרסה: מעלים את `version` ב-`package.json` ודוחפים ל-`main`. GitHub Actions בונה קובץ
התקנה על מחשב ווינדוס ומפרסם אותו ב-Releases, ומשם התוכנות המותקנות מתעדכנות.
פרטים למפתחים ב-`CLAUDE.md`.
