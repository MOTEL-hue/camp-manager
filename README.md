# ניהול קייטנות ומכירות

תוכנת ווינדוס בעברית לניהול רשימות, רישום לקייטנות, מכירת מוצרים (למשל ספרים), תשלומים,
הוצאות וסיכומים. עובדת בלי אינטרנט, ומתעדכנת לבד לגרסה חדשה כשיש חיבור.

## התקנה

1. נכנסים ל-[דף הגרסאות](https://github.com/MOTEL-hue/camp-manager/releases/latest) ומורידים את
   `camp-manager-setup-....exe`.
2. פותחים את הקובץ. ווינדוס עלול להציג "Windows protected your PC", כי לתוכנה אין חתימה
   דיגיטלית בתשלום. לוחצים **"מידע נוסף"** ואז **"הפעל בכל זאת"**. זה קורה רק בהתקנה הראשונה.
3. נוצר קיצור דרך בשולחן העבודה.

מכאן והלאה התוכנה בודקת לבד אם יש גרסה חדשה, מורידה אותה ומתקינה כשסוגרים את התוכנה.
הנתונים לא נפגעים בעדכון.

## איך עובדים

1. **רשימת אנשים** - פעם אחת לכל הפרויקטים. מקלידים ישירות בטבלה ("הוסף אדם" או "הקלדת רשימה"),
   או, רק אם נוח, מייבאים מאקסל או PDF (או גוררים את הקובץ לחלון). אפשר להוסיף עמודות משלכם.
   ילדים עם אותו טלפון הורה מזוהים כמשפחה אחת.
2. **פרויקט חדש** - למשל "קייטנת קיץ", "קייטנת אחרי סוכות" או "מכירת ספרים":
   - קייטנה: מחיר שווה לכולם או לפי כיתה, ומסמנים מי נרשמה.
   - מכירה: רשימת מוצרים ומחירים, ומקלידים כמה כל אחת קנתה.
   - אפשר להוסיף עמודות סימון (אישור הורים, הביאה טופס...) והנחה אישית.
3. **תשלומים** - בכפתור 💰 ליד כל שם: סכום (גם חלקי), אמצעי תשלום, תאריך. תשלום למשפחה שלמה
   מתחלק לבד בין הילדים. אחרי כל תשלום - קבלה להדפסה או לשמירה כ-PDF.
4. **הוצאות** - זמרת, גרפיכל, נסיעות... ומולן מאזן: כמה יש עכשיו, כמה יהיה כשכולם ישלמו, וכמה
   מזומן אמור להיות בקופה.
5. **סיכום** - לפי כיתה, לפי אמצעי תשלום, לפי מוצר, ורשימת חייבים (הדפסה / העתקת טלפונים).
6. **הזמנה וחלוקה** - כמה להזמין מכל מוצר, ורשימת "קיבלה" לסימון בזמן החלוקה.
7. **היסטוריה** - פרויקטים ישנים עוברים לארכיון. אפשר לשכפל פרויקט לשנה הבאה.

כל שינוי נשמר מיד. **Ctrl+Z** מבטל את הפעולה האחרונה. בכל יום נשמר גיבוי אוטומטי (30 ימים
אחורה), ובמסך "הגדרות וגיבוי" אפשר לשמור קובץ גיבוי ולשחזר ממנו.

## פיתוח

```bash
npm install
npm start        # מריץ את התוכנה
npm test         # בדיקות החישובים והייבוא
```

פרסום גרסה: מעלים את `version` ב-`package.json` ודוחפים ל-`main`. GitHub Actions בונה קובץ
התקנה על מחשב ווינדוס ומפרסם אותו ב-Releases, ומשם התוכנות המותקנות מתעדכנות.
פרטים למפתחים ב-`CLAUDE.md`.
