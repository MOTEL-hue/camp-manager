# רעיונות ושלבים הבאים

מה שעלה ועוד לא נכנס לתוכנה, ולמה. מה שנכנס - נמחק מכאן.

## שלב 2 (מתוכנן)

- **סנכרון בין שני מחשבים דרך האתר ב-Render.** קוד שיתוף שנותנים לאדם השני; כל אחד עובד גם בלי
  אינטרנט, וכשיש חיבור השינויים מתמזגים. דורש API באתר `virtual-chat` (אפליקציה חדשה שם).
- **תזכורות במייל מה-Gmail של בעל התוכנה.** כפתור "שלח תזכורת לכל החייבים" + שליחת קבלה במייל
  בלחיצה. דורש הגדרה חד-פעמית של הרשאת Gmail (דרך האתר, שכבר מחובר ל-Gmail).
- **תזכורת קולית - צינוק מקו ימות המשיח:** "שלום, נשאר לתשלום X שקל עבור הקייטנה". דרך האתר,
  שכבר מחובר לימות המשיח. עולה יחידות שיחה.
- **שלוחת בירור יתרה בקו:** ההורה מתקשר ושומע כמה נשאר, לפי המספר המזוהה. בלי עלות.

בינתיים: בלשונית "סיכום" יש "העתק טלפונים" של כל החייבים (אפשר להדביק לקמפיין בימות המשיח),
והקבלה נשמרת כ-PDF לצירוף למייל.

## רעיונות נוספים

- חתימה דיגיטלית לקובץ ההתקנה (כדי שווינדוס לא יציג אזהרה) - עולה כסף בשנה, לא נחוץ כרגע.
- זיהוי טקסט (OCR) ל-PDF סרוק - כבד; כרגע PDF סרוק מקלידים ידנית.
- תשלומים בהוראת קבע / תשלומים חודשיים מתוכננים.
